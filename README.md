# YT Downloader (School Project)

Frontend: static HTML/CSS/JS (Vercel).
Backend: Flask + yt-dlp + FFmpeg (Hugging Face Spaces, Docker).

## Local dev
Backend:
    cd backend
    python -m venv .venv
    .venv\Scripts\activate     (Windows)
    pip install -r requirements.txt
    python app.py

Frontend:
    cd frontend
    python -m http.server 8000
    open http://localhost:8000
